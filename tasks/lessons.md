# Packaging lessons

- Run the upstream link checker with the plugin root as cwd; its input paths are cwd-relative.
- Copy shared templates as well as references: FME workflows depend on templates/operation-summary.md.

- Follow official navigation links when adding documentation URLs; the Antigravity CLI installer page is /docs/cli/install/.

- Keep PDF-derived instructions, public documentation, and observed runtime results separate. Do not infer installed-plugin replacement behavior from an install command or carry personal-repository URLs into an organization clone.
